Source code for the game engine
===============================

The program in engine/freedoom.wasm and engine/freedoom.js is Crispy Doom 6.0
built for web browsers. Crispy Doom is free software under the GNU General
Public License, version 2 (COPYING-GPL2.txt, in this directory). That licence
gives you the right to the complete source for the program you were given.
Here it is.

1. The engine, unmodified
   ../source/crispy-doom_6.0.orig.tar.gz
   This is the upstream release, exactly as published by its authors and as
   shipped in the Ubuntu 24.04 "crispy-doom" source package.
   Upstream: https://github.com/fabiangreffrath/crispy-doom

2. The changes made for the browser
   https://github.com/radoslav1992/chiken-attack/tree/main/tools/freedoom
   - crispy-doom-6.0-web.patch   small changes to seven engine files
   - web/                        the browser platform layer: video, input,
                                 sound effects, music, on-demand game data
                                 and stand-ins for the parts of SDL2 the
                                 engine expects
   - lzma/                       the LZMA decoder from the LZMA SDK by Igor
                                 Pavlov, which is in the public domain
   - build.sh                    the build script
   - make-packs.py               cuts the game data into the files in data/
   - README.md                   how to rebuild, step by step
   These files are under the GNU General Public License, version 2 or later.

To rebuild: install Emscripten 3.1.6, unpack the tarball, apply the patch and
run build.sh. README.md has the exact commands.

The game data
=============

The files in data/ are Freedoom: Phase 2, version 0.13.0 (freedoom2.wad), cut
into pieces so that the game can start before all of it has downloaded, and
compressed with LZMA. Nothing in it is changed: put back together in the order
packs.json gives, the pieces are the original file exactly, and
tools/freedoom/make-packs.py in the repository above will do that for you
("unpack"). It is distributed under a BSD licence (COPYING-FREEDOOM.txt); its
source is at https://github.com/freedoom/freedoom
